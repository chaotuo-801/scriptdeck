# ScriptDeck v0.1.0

首个公开版本。

## 功能

- 服务管理：新建、编辑、复制配置、删除，支持 Node / Python / PowerShell / CMD / EXE
- 进程控制：启动、停止、重启，停止时兜底强杀整棵进程树
- 实时日志：跟随、过滤、清空、打开目录，按大小轮转
- 健康检查：进程存活、端口可连、HTTP 探活，显示最近结果与延迟
- 异常处理：退出码横幅、自动重启与指数退避、重启次数上限
- 目录导入：自动识别解释器、端口与环境变量，导入前提示端口冲突
- 托盘：状态色图标、快捷启停、全部停止、开机自启
- 主题：深色 / 浅色 / 跟随系统
- 编辑页逐项内联说明（ⓘ）

## 安装

- `ScriptDeck.Setup.0.1.0.exe`：安装版
- `ScriptDeck-0.1.0-portable.exe`：便携版

系统要求 Windows 10/11 x64。安装包未签名，首次运行请通过 SmartScreen 的「更多信息 → 仍要运行」。

## 已知问题

- 进程树结束与端口归属查询依赖 Windows 内置命令
- 暂无自动更新与代码签名
